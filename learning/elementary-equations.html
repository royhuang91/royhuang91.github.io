01 / 先抓住一个不变的关系

两边一样多，就要一起变

等号说的是“相等”

等号左边和右边的数量相同。8 = 5 + 3 也正确，等号不是“后面写答案”的命令。

x 是一个等待确定的数

含有未知数的等式叫方程。找到让左右相等的 x，就是解方程。同一题中的 x 表示同一个数。

两边做相同的操作

同时加、减同一个数，或同时乘、除同一个不为 0 的数，可以保持等式的解不变。除数不能是 0。

本页只讨论正数或 0 范围内的简单题，不用负数和复杂分数。方块表示数量，线段表示整体、部分或等份关系；示意长度不作为测量条件，以文字标注为准。蓝色带 x 的盒子表示未知数。

图解 01 / 等式与未知数

等号是一架平衡的天平

等号表示两边的数量相等。一个数暂时不知道，可以用 x 表示；这里的 x 是字母，不是乘号 ×。

第 1 步 · 先读等号

3 + 2 = 5

读作“三加二等于五”。等号说明左右一样多，5 = 3 + 2 也成立。

第 2 步 · 把不知道的数装进盒子

x + 2 = 5

含有未知数的等式叫方程。这里要找一个数，使它加 2 后恰好等于 5。

第 3 步 · 把答案放回去试

x = 3；3 + 2 = 5

让方程左右两边相等的未知数的值，叫方程的解。注意：x + 2 只有式子、没有等号，不是方程。

图解 02 / 加法方程

多出来的 3，两边一起拿走

解方程 x + 3 = 8。目标是让等号的一边只留下一个 x。

第 1 步 · 看清原来的平衡

x + 3 = 8

不能只从左边拿走 3，否则左右就不一样多了。

第 2 步 · 两边同时减 3

x + 3 − 3 = 8 − 3

同样多的两边减去同一个数，剩下的仍然同样多。左边的 +3 和 −3 正好抵消。

第 3 步 · 只剩一个 x

x = 5

检验：把 x = 5 代入原方程，左边 5 + 3 = 8，等于右边，所以解正确。

图解 03 / 减法方程 / 未知被减数

拿走了 3，就把 3 加回来

解方程 x − 3 = 5。原来有 x，拿走 3，还剩 5。

第 1 步 · 把整体与部分画出来

x − 3 = 5

x 是原来的总量，不是拿走的那部分。要找原来有多少，把拿走的和剩下的合起来。

第 2 步 · 两边同时加 3

x − 3 + 3 = 5 + 3

等式两边加上同一个数，仍然相等。左边的 −3 和 +3 抵消。

第 3 步 · 恢复原来的总量

x = 8

检验：8 − 3 = 5，等于原方程右边。这里用加法恢复被减去之前的数量。

图解 04 / 乘法方程

3 个一样的盒子，平均分成 3 份

解方程 3 × x = 12。3 × x 也可以简写为 3x，表示 3 个 x 相加。

第 1 步 · 认出 3 个相同的 x

3 × x = 12

同一道方程里的每个 x 表示同一个数。不能把三个盒子随意分成不同的数量。

第 2 步 · 两边同时除以 3

(3 × x) ÷ 3 = 12 ÷ 3

等式两边除以同一个不为 0 的数，仍然相等。左边 3 个 x 分成 3 份，每份就是 x。

第 3 步 · 看其中的一份

x = 4

检验：3 × 4 = 12。不能只把右边除以 3，而让左边还写成 3 × x。

图解 05 / 除法方程 / 未知被除数

每份有 4，合回 3 份就是全部

解方程 x ÷ 3 = 4。总数 x 平均分成 3 份，每份是 4。

第 1 步 · 分清总数和每份数

x ÷ 3 = 4

x 是总数。要从一份回到全部，需要把 3 份合起来。

第 2 步 · 两边同时乘 3

(x ÷ 3) × 3 = 4 × 3

等式两边乘同一个数，仍然相等。这里乘 3，让左边先除以 3 再乘 3，恢复为 x。

第 3 步 · 求出总数

x = 12

检验：12 ÷ 3 = 4。与 3 × x = 12 对照：一个已知总数求每份，一个已知每份求总数。

图解 06 / 减法方程 / 未知减数

8 减去一个数，剩下 3

解方程 8 − x = 3。先看 x 在哪里：它是拿走的数量。

第 1 步 · 先画已知的整体

8 − x = 3

这和 x − 3 = 5 不同：现在总量 8 已知，未知的是减去多少。不能看见减号就算 3 + 8。

第 2 步 · 两边同时加 x

8 − x + x = 3 + x

左边减 x 再加 x，恢复成 8，得到 8 = 3 + x。这一步两边加的是同一个未知数，也能保持相等。

第 3 步 · 两边再同时减 3

8 − 3 = 3 + x − 3

先把右边写成 x + 3 再看，也很好理解。等号左右交换不改变相等关系，所以 x = 5。

第 4 步 · 回到原题检验

x = 5；8 − 5 = 3

因此解是 x = 5。减法中未知数的位置会改变求解方法，要先分清整体与部分。

图解 07 / 除法方程 / 未知除数

分成 3 份，每份到底有多少

解方程 12 ÷ x = 3。本题把它理解为：12 个物品，每份装 x 个，能装 3 份。x 不能是 0。

第 1 步 · 给除法一个具体意思

12 ÷ x = 3

注意和 x ÷ 3 = 4 比较：这里的 x 在除号后，是除数；不是总数。

第 2 步 · 按数量关系改写

3 × x = 12

依据“除数 × 商 = 被除数”来改写。这里不是把两边除以 12，也不是随意交换除号前后的数。

第 3 步 · 两边同时除以 3

x = 12 ÷ 3 = 4

检验：12 ÷ 4 = 3，等于原方程右边，且 4 不为 0。未知除数与未知被除数要分开看。

图解 08 / 两步方程

先拆外层，再拆里面

解方程 2 × x + 3 = 11。先把“2 个 x”看成一个整体。

第 1 步 · 看清计算的顺序

2 × x + 3 = 11

先处理整体外面多出的 3，再把两个相同的 x 平均分开。不要只把 11 除以 2。

第 2 步 · 两边同时减 3

2 × x + 3 − 3 = 11 − 3

右边 11 − 3 = 8；左边只剩下两个 x。此时还不是 x = 8。

第 3 步 · 两边同时除以 2

(2 × x) ÷ 2 = 8 ÷ 2

等式两边同时除以 2，得到 x = 4。每一步只解开一层，写清楚两边做了什么。

第 4 步 · 放回最开始的方程

x = 4；2 × 4 + 3 = 11

检验必须代入原方程：2 × 4 + 3 = 8 + 3 = 11。这样既检查了乘法，也检查了加法。

03 / 基础 · 先找 x 的位置

基础 6 题：一步关系先看清

每题先在纸上写清两边做了什么，再展开提示和解答。

练习 01

解方程 x + 4 = 10。

先看一点提示

两边怎样同时拿走多出的 4？

展开完整解答与检验

两边同时减 4：x + 4 − 4 = 10 − 4，所以 x = 6。

代回原题：6 + 4 = 10。

练习 02

解方程 x − 7 = 5。

先看一点提示

未知的是原来的总数，需要把哪一部分加回来？

展开完整解答与检验

两边同时加 7：x − 7 + 7 = 5 + 7，所以 x = 12。

代回原题：12 − 7 = 5。

练习 03

解方程 4 × x = 20。

先看一点提示

4 个相同的 x 合起来是 20，每份多少？

展开完整解答与检验

两边同时除以 4：(4 × x) ÷ 4 = 20 ÷ 4，所以 x = 5。

代回原题：4 × 5 = 20。

练习 04

解方程 x ÷ 5 = 3。

先看一点提示

已知每份 3，一共有 5 份，怎样合回总数？

展开完整解答与检验

两边同时乘 5：(x ÷ 5) × 5 = 3 × 5，所以 x = 15。

代回原题：15 ÷ 5 = 3。

练习 05

解方程 14 − x = 6。

先看一点提示

14 是整体，6 是剩下的部分，未知的是另一部分。

展开完整解答与检验

两边同时加 x：14 = 6 + x；再同时减 6：8 = x，所以 x = 8。

代回原题：14 − 8 = 6。

练习 06

解方程 24 ÷ x = 6。

先看一点提示

每份装 x 个，装了 6 份，一共 24 个。

展开完整解答与检验

由除法的意义得 6 × x = 24，两边同时除以 6，所以 x = 4（且 x 不能为 0）。

代回原题：24 ÷ 4 = 6。

04 / 进阶 · 每次只拆一层

进阶 6 题：多一步，也别跳步

先判断最外层是什么运算，消掉它以后，再处理里面的关系。

练习 07

解方程 3 × x + 2 = 17。

先看一点提示

先拿走外面多出的 2，再把剩下的平均分成 3 份。

展开完整解答与检验

两边同时减 2，得 3 × x = 15；再同时除以 3，得 x = 5。

代回原题：3 × 5 + 2 = 17。

练习 08

解方程 4 × x − 3 = 21。

先看一点提示

原来的 4 个 x，比剩下的 21 多多少？

展开完整解答与检验

两边同时加 3，得 4 × x = 24；再同时除以 4，得 x = 6。

代回原题：4 × 6 − 3 = 21。

练习 09

解方程 x ÷ 4 + 2 = 5。

先看一点提示

先把 +2 抵消，还剩一份的数量；总数有 4 份。

展开完整解答与检验

两边同时减 2，得 x ÷ 4 = 3；再同时乘 4，得 x = 12。

代回原题：12 ÷ 4 + 2 = 5。

练习 10

解方程 18 − x = 7。

先看一点提示

不要只看减号，先确认 x 是被减数还是减数。

展开完整解答与检验

两边同时加 x，得 18 = 7 + x；再同时减 7，得 11 = x，所以 x = 11。

代回原题：18 − 11 = 7。

练习 11

解方程 35 ÷ x = 5。

先看一点提示

把除法改写成“每份数量 × 份数 = 总数”。

展开完整解答与检验

改写成 5 × x = 35，两边同时除以 5，得 x = 7（且 x 不能为 0）。

代回原题：35 ÷ 7 = 5。

练习 12

解方程 2 × (x + 3) = 18。

先看一点提示

现在最外面是“2 份”，先求每一份，再拆开括号里的 +3。

展开完整解答与检验

两边同时除以 2，得 x + 3 = 9；再同时减 3，得 x = 6。

代回原题：2 × (6 + 3) = 18。

05 / 应用 · 把生活写成等式

应用 4 题：先列方程，再求解

先说清楚 x 表示什么，找到等量关系，再列方程。算完后检查数值与单位。

练习 13

小雨有一些贴纸，又得到 6 张，现在有 19 张。原来有多少张？请先设未知数，再列方程。

先看一点提示

把“原来 + 又得到 = 现在”写成等量关系。

展开完整解答与检验

设原来有 x 张。列方程 x + 6 = 19；两边同时减 6，得 x = 13。答：原来有 13 张。

代回原题：13 + 6 = 19，符合题意。

练习 14

3 本同价的本子，加上一支 2 元的笔，一共 20 元。每本本子多少元？

先看一点提示

先写“本子的总价 + 笔价 = 总价”，别把本数当成本子的单价。

展开完整解答与检验

设每本本子 x 元。3 × x + 2 = 20；两边减 2 得 3 × x = 18，再同时除以 3，得 x = 6。答：每本 6 元。

代回原题：3 × 6 + 2 = 20（元），符合总价。

练习 15

一段 30 米的绳子，剪去一段后还剩 12 米。剪去了多少米？

先看一点提示

设剪去 x 米。这里的 x 在减号前还是后？

展开完整解答与检验

设剪去 x 米。30 − x = 12；两边同时加 x 得 30 = 12 + x，再同时减 12 得 x = 18。答：剪去 18 米。

代回原题：30 − 18 = 12（米），符合题意。

练习 16

有 36 颗珠子，每袋装同样多，正好装了 9 袋。每袋装多少颗？请用未知数作除数列方程。

先看一点提示

“总数 ÷ 每袋数量 = 袋数”，袋数 9 应写在等号哪一边？

展开完整解答与检验

设每袋装 x 颗。36 ÷ x = 9（x 不为 0）；改写为 9 × x = 36，再两边除以 9，得 x = 4。答：每袋装 4 颗。

代回原题：36 ÷ 4 = 9（袋），符合题意。

06 / 做完以后，再问自己

别让运算符号骗了你

只改一边，天平还平吗？
x + 3 = 8 不能写成 x = 8。左边减 3，右边也必须减 3。
减号前后的 x，是一回事吗？
x − 3 = 5 的解是 8；8 − x = 3 的解是 5。先分清原有、拿走、剩下，别套“看到减号就加”的口诀。
除号前后的 x，是一回事吗？
x ÷ 3 = 4 求总数，x = 12；12 ÷ x = 3 求每份数，x = 4。除数 x 不能为 0。
两步方程，真的拆完了吗？
2 × x + 3 = 11，先得 2 × x = 8，还要两边除以 2，才有 x = 4。有括号时先看最外层，如 2 × (x + 3) = 18 先除以 2。
乘 0 或除以 0，可以吗？
不能除以 0。两边乘 0 虽然得到相等的 0 = 0，却丢掉了原来的条件，不能用它来找出 x。
答案放回的是原方程吗？
把求出的值代回最开始的题，分别算出左右两边。应用题还要写单位，检查答案是否符合故事里的条件。

记住一个目标就好：保持两边相等，一步一步，让一边只剩一个 x。
